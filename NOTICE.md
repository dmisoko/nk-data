# Data provenance and notices

This repository aggregates refractive index data from several public and
third-party sources. The original per-source files are kept unchanged in their
directories; `db/`, `catalog.json` and `catalog/ranges.json` are derived files
generated by `tools/build_db.py`.

| Directory / source | Origin | Notes |
|---|---|---|
| `palik/` | *Handbook of Optical Constants of Solids*, ed. Edward D. Palik (Academic Press) | Copyright 1985/1991 Academic Press; data reproduced by permission in the original distribution. |
| `sopra/` | SOPRA S.A. refractive index database | Commercial database; redistributed here for research convenience. |
| `windt/` | D. L. Windt, *Software for modeling soft X-ray multilayers* (IMD) | Wavelength column is in Angstrom in the source files. |
| `rii/` | refractiveindex.info (M. Polyanskiy) | Individual entries retain their original literature citation. |
| `freesnell/` | FreeSnell (S. G. Johnson) material library | Source tables are indexed by photon energy in eV. |
| `litho/`, `coatings/`, `various/`, `analytic/` | Contributed experimental and modelled data from the original repository | See individual file headers. |
| `sources/kla/` | KLA (formerly Filmetrics) refractive index database, <https://www.kla.com/products/instruments/refractive-index-database> | Retrieved 2026-11-02 by automated browser capture. Values are attributed to the literature cited on each KLA page, most often Palik. |
| `sources/setfos/` | Setfos material library (Fluxim AG) | Supplied by the repository owner. |
| `sources/unight/` | Supplier material files | Supplied by the repository owner. The supplier `.nkk` model templates contained placeholder coefficients and were not imported. |

No warranty of accuracy is given. Numerical data may contain transcription
errors from the original sources; always validate against primary literature
or your own measurements before use in design or production.

If you are a rights holder and want material removed, open an issue in this
repository.
