nk - refractive index data for machines

Static, no authentication, no API key, no clone. A client resolves a material and fetches exactly one small JSON file.

Two requests

GET /catalog.json          search index (names, formulas, aliases, variants)
GET /db/<material>.<source>.json   one material, one source, wavelengths in nm

Every material file stores wl (nm, ascending), n and k as parallel arrays. A pol field distinguishes the ordinary / extraordinary ray.

Coverage

Over 1300 materials from Palik, SOPRA, Windt, refractiveindex.info, FreeSnell, Setfos and the KLA refractive index database. Coverage query: catalog/ranges.json.

Branch refs such as @master are moving pointers cached per CDN edge (about 12 hours) and will happily serve older bytes. Use the Pages base for the current revision, or substitute one commit SHA on every request in a batch and check catalog/manifest.json before trusting the payload.
